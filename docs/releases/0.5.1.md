# disclaude 0.5.1 Release Notes（草稿）

## 从 GitHub 安装

推荐直接安装固定标签，而不是跟随持续变化的 `main`：

```bash
npm install -g "github:hs3180/disclaude#v0.5.1"
disclaude --version
```

- 安装来源是 GitHub，不是 npm registry；根包可以保留 `private: true`。
- 需要 Git，建议使用 Node.js 20+。安装会下载依赖并通过 `prepack` 构建 TypeScript 包。
- 不要使用 `--ignore-scripts`，否则可能缺少运行所需的构建产物。
- 新安装的示例配置位于 `$(npm root -g)/disclaude/disclaude.config.example.yaml`。
  将其复制到 `~/.disclaude/disclaude.config.yaml`，配置后端、渠道及 workspace，
  创建相应 workspace 目录，再执行 `disclaude start`。
- 升级前备份现有配置和 workspace；不要用示例配置覆盖已有配置。

也可以使用 [README 中的源码安装方式](../../README.md#option-b-install-the-github-source-distribution)。
