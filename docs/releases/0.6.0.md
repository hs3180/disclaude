# Disclaude 0.6.0

Released 2026-09-24. The [published GitHub release](https://github.com/hs3180/disclaude/releases/tag/v0.6.0)
is the canonical source for assets and distribution provenance.

## Highlights

- **Agentic Research in existing Feishu Projects:** investigate from an ordinary
  Project conversation, deliver a readable report, and keep detailed sources and
  exploration records in the Project.
- **Evidence-led reports:** distinguish observations from interpretations, connect
  important judgments to evidence, and make alternatives and uncertainty clear.
- **Structured Codex input:** collect `requestUserInput` answers through Feishu
  cards and return them to the original turn.
- **Coordinated browser workflows:** share browser access between the user and
  agent, hand off control across tasks, and manage the coordinator with the service.
- **Reliability and packaging:** improve Codex outcome reporting, working-directory
  consistency, process cleanup, and installation from versioned GitHub tags.

## Compatibility and boundaries

- The source package is private to the repository. Install the prebuilt release
  from the [`v0.6.0` GitHub tag](https://github.com/hs3180/disclaude/releases/tag/v0.6.0);
  see the [installation and rollback guide](git-install.md).
- Research uses the existing Project, workspace, and agent harness. It does not
  introduce a separate research project type, runtime, task database, or control
  panel.
- Browser support does not guarantee access to every authenticated, challenged,
  or anti-bot-protected website.
- Research follow-up works through ordinary chat and supported structured input;
  native generation of secret (`isSecret`) questions is not promised for every
  model.
