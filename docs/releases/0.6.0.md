# disclaude 0.6.0

0.6.0 delivers Agentic Research in existing Feishu Projects and coordinated browser workflows, alongside reliability improvements to Codex interaction and prebuilt GitHub distribution.

## Highlights

- **Agentic Research in existing Projects.** Start from an ordinary Project conversation; investigate evidence; produce a human-readable Feishu report; keep detailed source material and exploration notes in the Project rather than cluttering the report; and continue through comments, chat, or a relevant structured follow-up.
- **Evidence-led reports.** Present the research question, key evidence, reasoning, alternative explanations, and conclusion boundaries. Distinguish observed results from interpretations and make material feedback visible in revisions.
- **Structured Codex input in Feishu.** Render `requestUserInput` questions as interactive cards, preserve question identity, and return submitted answers to the original turn.
- **Coordinated browser workflows.** Share browser ownership between agent and user, hand control across tasks, and use assisted Chromium setup and service lifecycle diagnostics on supported environments.
- **More reliable operation and packaging.** Improve Codex outcome reporting, project working-directory consistency, process recovery and cleanup, and isolated package-install acceptance.

## Compatibility and boundaries

- The root source package is private and is not published to the npm registry. The supported prebuilt distribution is a generated GitHub tag with `release-source.json` provenance; an optional `.tgz` must come from the same tested distribution commit.
- Use Node.js 20+ and npm 10+ for the prebuilt GitHub distribution. Follow the [Git installation and rollback procedure](git-install.md); preserve existing configuration, workspaces, sessions, and schedules during upgrades.
- Research reuses the existing Project, workspace, and agent harness. It does not add a separate Research project type, runner, task database, fixed workflow, or control panel.
- Research follow-up can use ordinary chat or non-sensitive structured input. Native generation of secret (`isSecret`) questions is not promised for every model.
- Browser lifecycle and collaboration do not guarantee retrieval from every authenticated, challenged, or anti-bot-protected website.

## Distribution provenance

The final source commit, generated distribution commit, source fingerprint, package-install matrix, and artifact checksum must be recorded against the tested candidate. The v0.6.0 tag and optional release asset are published only after the release PR is merged and final candidate acceptance is complete.
