# Disclaude 0.6.28: harness runtime management and named-channel migration fix

Release preparation, 2026-11-15. This patch release packages the reviewed
runtime at main `4cda15edc7`. Two merged fixes ship since 0.6.27: a unified
`disclaude harness` command family now lists, installs, and checks supported
agent runtimes (#5169; #5709), and named Feishu channel declarations now
register independently of the legacy single-app enable switch (#5736; #5742).
Release preparation changes only version metadata and documentation beyond
those reviewed changes.

## Changes

- Add `disclaude harness list`, `disclaude harness install`, and
  `disclaude harness doctor` for claude, pi, codex, and dsh (#5169; #5709).
  The catalog distinguishes PATH CLI binaries from pi's production Node
  module resolution, shows each default version and its source, and accepts
  `--version` or `DISCLAUDE_HARNESS_<ID>_VERSION` overrides. Installation
  plans are explicit and idempotent: matching installs are skipped, differing
  versions are upgraded, missing PATH links are repaired, and `--dry-run` /
  `--yes` control preview and confirmation. Doctor checks discoverability and
  gives authentication next steps without reading or writing API keys,
  tokens, or login sessions. The command family uses `harness` only; old
  `disclaude backend ...` invocations fail with the equivalent harness
  command instead of routing through a compatibility alias.
- Register named Feishu channel declarations whenever they are present,
  even when `channels.feishu.enabled: false` disables the legacy single app
  (#5736; #5742). Previously that migration combination silently produced
  zero channels. With no named declarations, the legacy single-app behavior
  is unchanged; regression coverage spans legacy enabled/disabled by
  declarations present/absent.

## Install and use

Requires Node.js 20+, npm 10+, and Git. After the release is published:

```sh
npm install -g "github:hs3180/disclaude#v0.6.28"
disclaude --version
```

**Upgrade note.** No configuration migration is required. The harness command
family is additive and the named-channel registration fix is automatic. Stop
the running service before upgrading and run `disclaude start` afterwards;
installation does not touch configuration, credentials, or workspace data.
Use the [installation/rollback guide](git-install.md) to switch releases; the
prior package remains installed for rollback.
