# Disclaude 0.6.20: test-suite preset deduplication

Release preparation, 2026-11-08. This patch release packages the reviewed
runtime at main `83965ebaa`. It is a tests-only release: the sole merged
change since 0.6.19 deduplicates the recurring test preset configuration
(#5679; #5721); behaviour assertions are unchanged and no production code
is touched. Release preparation changes only version metadata and
documentation beyond that scoped change. The final source commit, archive,
checksums, and fresh installation results are recorded in the release
assets.

## Changes

- Test preset configuration is deduplicated (#5679; #5721). The named-LLM
  bindings that recurred verbatim across the `resolved-agents` suites —
  the native and selected DSH bindings, the non-DSH binding selection, the
  Kimi tier overrides and the Claude tier environment stubs — are now
  constructed once by shared builders, and the loader suites embed one
  shared preset YAML fixture instead of repeating the same block, so
  repeated fixtures stay in sync from a single source of truth. Behaviour
  assertions are unchanged: the suites still assert the same resolution,
  validation and wire-model outcomes. Production code is not modified, and
  the built runtime is byte-identical to 0.6.19 apart from version
  metadata.

## Install and use

Requires Node.js 20+, npm 10+, and Git. After the release is published:

```sh
npm install -g "github:hs3180/disclaude#v0.6.20"
disclaude --version
```

**Upgrade note.** No configuration migration is required; 0.6.20 is a
drop-in replacement for 0.6.19. Existing deployments keep their registry
and workspace data; stop the running service before upgrading and run
`disclaude start` afterwards. Installation does not touch configuration or
workspace data. Use the
[installation/rollback guide](git-install.md) to switch releases; the
prior package remains installed for rollback.
