# Historical 0.5.0 release records

These documents and `acceptance.json` describe the 0.5.0 candidate work. The inventory is preserved for traceability; its 44 criterion IDs, candidate hashes, statuses and local evidence paths are historical data, not acceptance requirements for current releases.

The inventory previously lived at `tests/e2e/0.5.0/acceptance.json`. The dedicated `scripts/validate-release-evidence.mjs` and its fixture tests were removed during #5016 because they only enforced that fixed release plan and had no active release-workflow caller. Their source remains in Git history. Historical reports may retain the original paths and commands; they describe what ran then, not executable instructions for the current checkout.

Use the current release requirements and [test entry points](../../../tests/README.md) for new work. Historical records do not prove the current candidate passed.
