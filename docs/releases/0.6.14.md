# Disclaude 0.6.14: WeChat dynamic multi-account regression lock

Release preparation, 2026-11-05. This patch release packages the reviewed
runtime at main `79358ea6`, which adds one change to the release scope
(#5685, locking the WeChat dynamic multi-account semantics behind a
cross-component integration regression). Release preparation changes only
version metadata and documentation beyond that scoped change. The final
source commit, archive, checksums, and fresh installation results are
recorded in the release assets.

## Changes

- Lock in the WeChat dynamic multi-account invariants with a new
  cross-component integration regression (`wechat-dynamic-accounts`): two
  dynamically registered accounts are exercised through the real
  `WeChatRegistry`, `WeChatRegistrationRuntime`, `ChannelLifecycleManager`
  and `DisclaudeService` wiring — not hand-built channels — with the WeChat
  gateway stubbed per account host. The test asserts inbound isolation
  (the same peer and raw message id produce distinct qualified
  chat/message ids per account, and private `context_token` material
  never enters routing payloads), per-account outbound routing with each
  account's reply context, on-disk state isolation (per-account
  `accounts/<id>` directory with `auth.json` and `session.json` holding
  cursor, dedup and reply-context, plus the shared `peer-identities.json`
  binding), and restart recovery (accounts return healthy on the same
  registry root, replayed gateway messages are not redelivered, welcome
  messages are not resent, and reply context survives for outbound use).
  Production behavior is unchanged; the regression guards the already
  merged dynamic registration, isolation and recovery semantics (#5451;
  #5685).

## Install and use

Requires Node.js 20+, npm 10+, and Git. After the release is published:

```sh
npm install -g "github:hs3180/disclaude#v0.6.14"
disclaude --version
disclaude wechat status --check
```

Existing 0.6.13 deployments keep their configuration, WeChat registry, and
workspace data. Use the [installation/rollback guide](git-install.md) to
switch releases; the prior package remains installed for rollback. The
WeChat channel guide ([../wechat-channel.md](../wechat-channel.md)) covers
the registry directory, login commands, coexistence configuration, and
recovery behavior.

Automated coverage does not replace real-account acceptance: scanning,
online connections and credential expiry with two real WeChat accounts
remain outside the automated test scope and should be verified in your own
environment.
