# Disclaude 0.6.21: persistent per-chat agent selection

Release preparation, 2026-11-09. This patch release packages the reviewed
runtime at main `a811cd98b`. The merged change since 0.6.20 makes the existing
`/agent use <preset>` choice durable for each chat and adds per-application
agent defaults (#5476; #5702). Release preparation changes only version
metadata and documentation beyond that scoped change. The final source commit,
archive, checksums, and fresh installation results are recorded in the release
assets.

## Changes

- `/agent use <preset>` now saves the selected preset for the chat as well as
  activating it immediately (#5476; #5702). Later messages and new rounds reuse
  the saved choice without another switch, and the choice survives service
  restarts through `workspace/.disclaude/agent-selections.json`. Selection
  precedence is the current session's explicit switch, then the chat's saved
  choice, then the owning application's `channels.<app>.agent` default, then
  the global default. Feishu, static WeChat, and dynamically registered WeChat
  applications can declare the per-app default; chats that never switched keep
  their previous per-app/global behavior.
- No new command or bind/unbind parameter is introduced. A switch still starts
  a new native session without migrating context, and is refused while the
  current or another affected session is busy. The selection document is
  versioned and validated, written atomically with owner-only permissions, and
  a failed save leaves the existing session unchanged. A corrupt or unreadable
  document fails startup explicitly rather than silently discarding saved
  choices.

## Install and use

Requires Node.js 20+, npm 10+, and Git. After the release is published:

```sh
npm install -g "github:hs3180/disclaude#v0.6.21"
disclaude --version
```

**Upgrade note.** No configuration migration is required; 0.6.21 is a
drop-in replacement for 0.6.20. Existing deployments keep their configuration,
registry, and workspace data; stop the running service before upgrading and run
`disclaude start` afterwards. Installation does not touch configuration or
workspace data. To set an application default, add `agent: <preset>` to the
corresponding `channels.<app>` block; an in-chat `/agent use <preset>` choice
takes precedence. Use the [installation/rollback guide](git-install.md) to
switch releases; the prior package remains installed for rollback. See the
[agent configuration guide](../agent-configuration.md) for selection
precedence and persistence details.
