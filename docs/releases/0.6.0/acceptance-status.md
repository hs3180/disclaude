## 后续顺序与数据保护

先完成轻量实现的完整文档/聊天垂直用例，复用共享执行能力，避免继续扩展专用任务 schema 与入口。随后补开放调查、非研究长任务、真实并发和中断恢复，再覆盖故障与迁移，最终对同一发行候选验收。

真实生产机器人验收每轮保留当前配置与 workspace、避免竞争连接，结束后恢复日常服务并独立核验健康。测试文档、卡片、标签页和临时文件按实际归属清理；其他会话期间写入的记录不能作为测试垃圾删除。2026-09-17 三个验收临时目录的七份记录已按轮次和原相对路径归档回日常 workspace，逐文件 SHA-256 读回一致后才删除原目录，未覆盖或自动拼接日常聊天历史。

当前所有未满足项保持开放。CI 通过、恢复归档完成和本表存在，均不是 0.6.0 交付证明。
