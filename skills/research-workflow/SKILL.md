# 现有 Project 中的研究与报告

交付目标是飞书中的人类可读研究报告，以及围绕报告的真实反馈闭环；Skill 只提供方法，不替代报告、文档协作或用户可见的研究结果。

沿用当前 Project 的 workingDir、会话和 Agent harness。不要创建特殊 Research Project、模式、命令、任务状态文件或独立恢复流程。同一工作区续行是 harness 的通用能力。

## 调查与证据

- 先弄清用户要回答的问题、范围、约束和时效要求。只有当缺失信息或歧义可能改变判断时才追问；问题要具体、能区分不同解释。
- 自主选择合适的信息源和分析方式。围绕尚未解决的问题寻找有区分力的证据，并根据新证据调整调查方向；不要求固定阶段或预先填满计划。
- 关键陈述应能追溯到实际来源。把来源明确说了什么（观察到的结果）与 Agent 对其含义的解释（发现/判断）分开；标出矛盾、不确定性和证据强弱。
- 在 Project 内按需保存有助于核验或继续工作的来源资料、引用摘录、重要搜索线索和分析产物。只记录有复用或核查价值的内容，不把每次工具调用写成过程日志，也不强制特定归档文件名或目录结构。

## 报告生成与修订：发现逻辑

让读者看见 Agent 如何从问题走到判断，以及每个判断由哪些证据支撑。正文按问题、关键推理关系和有意义的转折组织，不按搜索或工具调用的时间顺序写流水账。可以先简明说明当前理解，再展开证据如何支持、削弱或改变它。

重要判断可用这个检查单元审阅：

> 问题 → 预期的区分性证据 → 实际观察 → 判断更新 → 下一步选择

不必把这些标签逐项写进每一节。报告按读者和研究问题灵活组织，但要做到：

- 说明关键证据改变或没有改变什么判断，并呈现从证据到解释的推理关系；
- 让来源事实、Agent 推断、替代解释和结论边界可辨认；
- 指出哪些新证据可能改变当前理解，以及重要未知或冲突；
- 在相关主张附近提供可核对的来源链接或引用。

报告不是研究日志，也不要求每项研究使用相同标题、阶段、长度或固定模板。正文只保留读者理解和核查结论所需的过程；详细探索记录、引用材料及其他存档材料放在 Project 内的其他记录中。

## 将反馈用于研究

当用户通过飞书文档评论、正文编辑或聊天反馈继续研究时，先读取当前相关内容和最新反馈，再定位它影响的问题、假设、证据、解释或结论。判断应采纳、进一步核验、追问还是有依据地不采纳；不能只回复“已收到”。

若反馈引入的歧义可能改变判断，先提出一个具体的区分性问题。适合选项或字段化回答时，复用当前可用的通用表单/交互卡片能力；否则直接在聊天中询问。不为研究另造卡片协议，也不因用户提供了可选方向就擅自开始额外调查。

收到回答后，将其用于同一研究，继续检查相关证据并修订报告。采用定点增量编辑，保留用户原有文字；若意见与文档内容冲突，显式说明并避免覆盖。修订后回读受影响内容，确认实际写入，并在报告或聊天中说明重要反馈如何处理以及它改变了什么。没有改变结论时，也简要说明理由；未解决的问题应如实保留。

## 项目档案与交付

飞书报告是面向人的成果；Project 内的其他记录用于存放较详细的来源材料、搜索线索和探索产物。档案支撑报告核查或后续研究，但不要把整份档案复制进正文。无需为每项研究机械生成完整调用日志或全部原始 API 快照。

完成或阶段性交付时，确认报告逻辑连贯、主要判断可追溯、边界和待解决问题明确；提供飞书文档链接，让用户可从当前 Project 继续讨论。若文档或评论读取不完整、写入结果不确定或同步失败，先核实可见状态；不能把未同步的修改说成已经交付。文档操作细节见[读写参考](references/protocol.md)；[报告示例](assets/research.md)只是可选起点。

## 方法参考

- Drake, John M. and Barbara A. Han. [“How to write a scientific paper in fifteen steps”](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1013505), _PLOS Computational Biology_ (2025). 参考其发现逻辑、叙事弧以及观察到的结果与解释性发现之间的区分；不照搬科学论文的固定结构。
- Booth, Wayne C. et al. [_The Craft of Research_, Fifth Edition](https://press.uchicago.edu/ucp/books/book/chicago/C/bo215874008.html), University of Chicago Press (2024). 参考其完整论述来检查主张、理由、证据、推理依据及对质疑的回应。
